# CampReady Prospective Validation

Temporary public repository used only for the CampReady prospective
source-monitoring validation.

The monitored information originates from public USFS and NWS sources.

This repository:

- sends no real user notifications;
- contains no credentials or API secrets;
- records only would-notify candidates;
- preserves deterministic CampReady relevance and delta rules;
- is intended to be removed after validation closeout.

The workflow is manual-only until the hosted public-runner gate passes.
