E. EXACT ROOT CAUSE
campready-phase4b.capture.load_module used importlib's normal module execution path to obtain reusable functions from a frozen CLI program. The frozen dependency has an unconditional final `raise SystemExit(main())`, not an `if __name__ == "__main__"` guard. Import therefore executed main(), which requires sys.argv[1] through sys.argv[5]. The hosted harness supplied no such dependency CLI arguments. The violated assumption was that importing the frozen CLI file was definition-only and would not invoke its command-line entrypoint.
This is a generic harness composition defect, not a source retrieval failure and not a heterogeneous semantic-model failure.
